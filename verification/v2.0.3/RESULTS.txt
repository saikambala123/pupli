Scope
Chromium tests run offline fixtures using the actual extension scripts and portal
model/change handlers. The editor test renders the real React component with an
isolated API transport. Persistence checks use the real Mongoose schema with
BSON serialization. API regressions cover data/query construction. No live
McDonald's application was submitted and no production MongoDB/Gemini credentials
were used. The production build used a randomly generated, build-only JWT_SECRET;
that value was not saved in the deliverable. Firefox package contents were
verified; Firefox itself was not launched.
